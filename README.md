# Enough Invoice Maker 🧾

A premium, high-fidelity Invoice Generator built with HTML, Vanilla CSS, and JavaScript. Optimized for branding, mobile responsiveness, and professional A4 PDF generation.

## ✨ Features
- **Dark Editor UI**: Sleek, modern interface for creating invoices.
- **Branded Invoices**: Orange & White professional theme.
- **Smart History**: Remembers your clients and companies for quick suggestions.
- **Robust PDF Generation**: High-quality A4 exports using `jsPDF` and `html2canvas`.
- **Pre-loaded Assets**: Uses `images.js` to ensure logos and QR codes load instantly even in offline/local environments.
- **Interactive**: Support for clickable Email, Instagram, and Website links.
- **Scan to Pay**: Integrated QR code payment section with custom UPI ID.

## 🚀 Getting Started
1. Clone the repository.
2. Ensure `index.html` and `images.js` are in the same directory.
3. Open `index.html` in your browser.
4. Fill in your details and download your professional invoice!

## 🛠️ Technical Details
- **Frontend**: HTML5, CSS3, JavaScript.
- **Libraries**: jspdf, html2canvas.
- **Storage**: LocalStorage for business settings and customer history.
